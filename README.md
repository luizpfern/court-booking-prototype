# Quadra
A prototype marketplace platform for booking sports courts (football, volleyball, beach tennis and tennis), developed as an academic project for a Software Engineering course at Universidade Paulista (UNIP).

This application is **only a visual and functional prototype**, created to demonstrate interface concepts, navigation flow, and possible product features. It does **not implement full business rules, payment flows, or real operational logic**, since the main purpose is to showcase UI/UX design and screen concepts that could support a real product in the future.

## Academic Context
This project was developed as a supervised practical activity (APS) for the Software Engineering discipline, 7th semester, Computer Science.
The scope covers requirements analysis, UML modeling, Scrum methodology and UI/UX prototyping.

## Overview
Quadra connects two types of users:
- **Users** — browse nearby establishments, view available courts and book time slots
- **Establishments** — register their courts, manage availability and track bookings
